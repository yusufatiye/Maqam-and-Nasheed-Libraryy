# ألطف المعاني — نسخة iPhone / Web V4

واجهة واحدة متجاوبة للويب وiPhone/iPad.

## أهم التحسينات
- لوحة البحث الكبيرة لم تعد Sticky؛ لا تغطي النتائج أثناء التمرير.
- لكل نشيد مفهرس ملاحظة شخصية قابلة للحفظ والبحث.
- لكل صفحة من الكتاب أيضاً ملاحظة شخصية قابلة للحفظ والبحث.
- مثال: اكتب «حضرة ذكر» كملاحظة على عدة أناشيد، ثم ابحث عن «حضرة ذكر» فتظهر تلك النتائج.
- تصدير/استيراد الملاحظات والمفضلة بملف JSON لنقلها يدوياً بين اللابتوب وiPhone.
- الملاحظات محلية على الجهاز ولا تُرسل للخارج.

## iPhone / iPad
1. ارفع محتويات هذا المجلد إلى استضافة HTTPS.
2. افتح الرابط في Safari على iPhone.
3. انتظر اكتمال أول تحميل.
4. من زر المشاركة اختر «إضافة إلى الشاشة الرئيسية».
5. افتح أيقونة ألطف المعاني. بعد التخزين الأول يعمل التطبيق دون إنترنت.

مهم: الملاحظات لا تتزامن تلقائياً بين الأجهزة. استخدم زر «بياناتي» ثم تصدير/استيراد لنقلها.

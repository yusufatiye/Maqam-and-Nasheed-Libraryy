# ألطف المعاني — V5 الاحترافي

هذه النسخة تعيد بناء التطبيق ليصبح موسوعة قصائد/أناشيد منظمة، مع تحسين خاص لأداء iPhone وعدم تعليق التمرير.

## ما الجديد
- **533 سجلاً منظماً** للأناشيد/القصائد المستخرجة من الكتاب، بدلاً من الاعتماد على نتيجة صفحة فقط.
- كل سجل يدعم: العنوان، المقام، الفرع، الكلمات، الشاعر، الملحن، الإيقاع/الوزن، رقم الشريط، صفحات PDF، صورة المصدر، وحالة الجودة.
- حالة الجودة منفصلة بوضوح:
  - `موثق يدوياً ✅`
  - `OCR يحتاج مراجعة ⚠️`
- **البحث المركب**: مثل `راست + يا رسول الله`.
- حقول بحث مباشرة: `مقام:`، `شاعر:`، `ملحن:`، `كلمات:`، `ملاحظة:`، `وسم:`، `قائمة:`، `إيقاع:`.
- بحث عربي مرن يتحمل بعض الأخطاء البسيطة مثل `اللة` بدلاً من `الله`.
- اقتراحات أثناء الكتابة.
- وسوم القصائد: سهل، صعب، مجلس خاص، تعطيرات نبوية، إنشاد، حضرة ذكر سريعة، حضرة ذكر بطيئة، أداء فريدة.
- ملاحظات شخصية قابلة للبحث.
- قوائم شخصية قابلة للبحث.
- تسجيل صوتي محلي لكل نشيد + رابط تسجيل + علامات زمنية.
- صفحة النشيد: الكلمات / المعلومات / الصفحة الأصلية / التسجيل / الملاحظات والوسوم / تعديل المدير المحلي.
- وضع إنشاد: تكبير/تصغير، وضع ليلي، ملء شاشة، تمرير تلقائي، ومحاولة إبقاء الشاشة مستيقظة عندما يسمح الجهاز.
- مشاركة برابط مباشر، QR، نسخ الكلمات، طباعة أو حفظ PDF.
- نسخة احتياطية واستعادة للملاحظات والوسوم والمفضلة والقوائم والتصحيحات وروابط التسجيل والعلامات الزمنية.
- إضافة قصيدة/نشيد وصورة مصدر شخصية محلياً.
- وضع مدير محلي لتصحيح OCR دون تغيير صورة المصدر الأصلية.

## تحسين iPhone والأداء
تم التخلص من ملف JavaScript الضخم (~59 MB) في نسخة الويب. بيانات الفهرس الأولية أصبحت قرابة 2.1 MB فقط، وصور الصفحات الـ427 تُحمّل عند الحاجة. هذا يقلل الذاكرة والضغط على Safari.

لم يعد التطبيق يستخدم `body overflow lock` أو اعتراض `touchmove/preventDefault` الذي قد يسبب تعليق التمرير. نوافذ النشيد نفسها تمرر داخلياً باستخدام iOS momentum scrolling.

## عارض الصفحة الأصلية
- القوائم **مخفية افتراضياً** عند فتح الصورة.
- اضغط على الصورة لإظهار/إخفاء القوائم.
- تكبير من 50% إلى 300%، أزرار + و−، وملاءمة.
- التمرير والتكبير بإصبعين مسموحان على iPhone.
- في الوضع الأفقي تتكيف الصورة مع عرض شاشة iPhone، ويمكن تغيير حجمها أيضاً.
- زر تدوير 90° متوفر عند إظهار القوائم.

## جودة الفهرسة
الفهرس المنظم الحالي يحتوي 533 سجلاً. **8 سجلات موثقة يدوياً بالكامل حالياً، و525 سجلاً ما زال موسوماً OCR يحتاج مراجعة**. لا يتم تقديم OCR على أنه نص نهائي؛ صورة الصفحة الأصلية تبقى المرجع الأعلى دائماً، ويمكنك تصحيح السجل من وضع المدير المحلي.

## تشغيل الويب/PWA
ارفع محتويات المجلد كما هي إلى GitHub Pages أو أي HTTPS. لا تغيّر بنية `data/` أو `pages/`.

## نسخة اللابتوب
يوجد ملف مستقل منفصل باسم `ألطف_المعاني_لابتوب_V5.html` يحتوي البيانات والصور داخله ويعمل بدون مجلدات خارجية.
